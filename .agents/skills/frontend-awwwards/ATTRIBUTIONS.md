# ATTRIBUTIONS & LICENSES

This master skill, **frontend-awwwards**, unifies research, code architectures, design principles, audit heuristics, and animation techniques from 17 world-class open-source repositories and creative engineering frameworks.

All original source repositories remain completely intact within the `sources/` directory, preserving their original git histories, internal structures, licenses, and documentation.

## Usage Guidelines & License Compliance

1. **Original Integrity:** The sources in `sources/` must remain untouched and preserve all license files.
2. **Attribution Preservation:** When exporting or adapting code patterns from these libraries into client or production projects, keep relevant author acknowledgments.
3. **Reference Not Blind Copying:** Use these repositories as deep intellectual foundations, design systems, and audit benchmarks.
